Editorial Note on Agentic Aesthetics Repository Architecture

Generic, uncurated AI web generation typically suffers from predictable visual fatigue: sterile gray palettes, uniform cards, and forgotten responsive edges. This repository functions as a deliberate antidote. Stored within .agents/skills/, each skill equips the AI agent with strict domain principles and guardrails.

The showcases catalogued below are living reference outputs—independent personal finance dashboards generated strictly under each skill's philosophy.

"Form and typography should reveal, not conceal, the intent of the builder." DIR: /.agents/skills/

How to Install a Discipline into Your Project Developer Guide

To inject any of these visual standards into your own project, copy its folder directly into your workspace's .agents/skills/ directory:

cp -r .agents/skills/style-spatial-glass /path/to/my-project/.agents/skills/

Then invoke the skill in conversation: /style-spatial-glass create a personal finance dashboard
